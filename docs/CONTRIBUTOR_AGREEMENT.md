# 贡献者协议（简版）

提交贡献即表示你同意以下条款：

1. **许可**：代码贡献按 MIT；教学内容按 CC BY-SA 4.0，允许复制、改编与再分发，需署名并以相同方式共享。
2. **原创与授权**：你拥有提交内容的权利，或已获得许可；不提交盗版教材、付费题库、未授权图片或患者数据。
3. **无 PHI**：禁止提交姓名、住院号、检查号、面部/纹身等可识别信息；波形需脱敏并确认机构允许使用。
4. **医学依据**：诊断标准、剂量、能量、禁忌与处理建议需给出可追溯来源；不把教学示意写成临床指令。
5. **AI 辅助披露**：使用生成式 AI 起草内容需人工核对并在 PR 中说明；AI 不得作为唯一医学依据。
6. **审阅配合**：同意维护者进行编辑、医学与安全审阅；重大修改可能要求补充来源或缩小表述。
7. **行为准则**：尊重学习者与同行；不发布歧视、骚扰、广告或恶意代码。
8. **无担保**：内容为教学用途，不构成医疗建议；贡献者不因本站内容对临床决策承担责任。

安全问题请按 `SECURITY.md` 私下报告；内容勘误请按 [`CORRECTIONS.md`](CORRECTIONS.md)。
