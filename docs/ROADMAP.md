## 内容治理原则

1. 先讲机制与判读路径，再讲记忆口诀；不以“图片记忆”替代电生理理解。
2. 诊断标准、药物剂量与能量范围必须注明适用场景；不提供个体化诊疗指令。
3. 每章保留“边界与陷阱”，明确正常变异、伪差与鉴别诊断。
4. 新增/修改内容先跑 `scripts/validate_curriculum.php` 与相关测试，再提交审阅。
5. 明确区分“编辑核对”与“临床同行审阅”；未完成的审阅不写成已完成。
