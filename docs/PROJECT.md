# 心迹 ECG Lab — 项目说明

## 一句话

面向医学生、住院医师与急救培训者的**心电图判读 + ACLS 急救推演**双语汇（中文界面）教学站，竖屏手机与横屏大屏同源适配，浅色/深色双主题。

## 比赛目标

- 在 **2026-11-09 00:00** 前交付可公网访问的完整站点。
- 两个核心板块：
  1. **学习**：从窦性心律、期前收缩、逸搏、ST-T 改变到传导阻滞、电解质紊乱，覆盖 230 章、19 个章节；其中 40 种判读诊断 + 184 个理论/病例专题；每种包含机制、诊断标准、鉴别、处理、易错点与可交互心电图。
  2. **实操**：生成心电图并作答（单选/多选诊断）；ACLS 急救场景推演（CPR、同步电复律、非同步除颤、肾上腺素等）。
- 附加：钾/钙电解质实验室，实时观察 ECG 形态变化。
- 两套主题、三档响应式断点（竖屏手机 / 平板·折叠屏 / 桌面）。
- 详细文档、自动化测试、可复现部署。

## 目标设备

| 设备 | 断点 | 布局策略 |
|---|---|---|
| 竖屏手机 WAP | < 720px | 单列、底部导航、ECG 自适应疏密网格、操作面板底部抽屉 |
| 平板 / 横屏折叠屏 | 720–1180px | 双列、可折叠侧栏、ECG 横向利用 |
| 桌面 | > 1180px | 固定侧栏 + 内容栅格、12 导联并排、浮动目录 |

## 非目标

- 不做真实医疗诊断或替代医生判断；全站标注教学用途。
- 不追求真实 12 导联电生理级仿真；波形为教学用途的形态学近似，但关键诊断特征、间期、节律关系保持医学上自洽。
- 不接入真实患者数据；无 PHI。

## 交付物

- 可运行站点（nginx + PHP-FPM 8.4 + MySQL 8.4）。
- 230 章结构化心电图课程（19 个章节；40 种判读诊断 + 184 个理论/病例专题）+ 交互式 ECG 查看器。
- 练习题库：1920 道确定性预生成病例（40 种诊断 × 40 个种子 + 8 组组合 × 40），服务端仍按 seed 重建 ECG 并判分。
- 10 个 ACLS 推演场景（含 PEA 低血容量、低温、LAST、妊娠心脏骤停）与自动复盘。
- 电解质实验室。
- README、架构、设计、医学、API、测试、部署、数据库文档。
- PHP/JS 单元测试、API 集成测试、关键页面多视口截图验收记录。

## 约束

- 服务器内存约 3.5 GB，禁用重型前端构建与频繁浏览器自动化；前端采用零构建 ES Modules。
- 不触碰 `/www/wwwroot` 下任何现有生产目录；本项目使用独立目录 `/www/wwwroot/ecg-academy` 与独立数据库 `ecg_academy`。
- 部署只新增 nginx vhost 文件，不修改其他站点配置。
