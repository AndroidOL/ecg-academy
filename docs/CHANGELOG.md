# 版本记录

## 3.0.15 — 2026-11-09

- Passkey 登录支持免用户名：未填写用户名时使用 discoverable credential，由浏览器直接选择本机 Passkey；密码登录仍需用户名。
- AI 状态修正：`configured/mode/provider` 反映服务端是否配置，不再因访客身份显示“本地”；生产 AI 全局开关已启用并测试 DeepSeek 返回 OK。
- 波形优化：房扑锯齿改为平滑边缘 + 轻微频率/幅度摆动；MI/ST-T 改为带斜率、曲率和逐搏微小差异的平滑段，减少僵硬感。
- 标注按导联过滤：解析 `V1–V4`、`II/III/aVF` 等标签或读取 `leads` 元数据；房扑、前壁 MI、LBBB 增加明确导联；LBBB 不一致性 ST-T 拆成侧壁 ST↓/T 倒置与 V1–V3 ST↑/T 高尖，并修正时间位置。
- 性能：向量画布不再每帧重设尺寸；12 导联图不再随每帧重绘；动画在移动端 30fps、桌面 45fps；DPR 移动端上限 1.5；后台标签页跳过绘制。向量页 ScriptDuration 从约 7.6s/8s 降至约 0.48s/8s。
- 测试：PHP 全量 93 项通过；passkey 免用户名、标注导联解析、ECG 引擎、复习/向量模型均通过。
- 资源版本 `20261109ar`。

## 3.0.13 — 2026-11-09
