# 区域指南差异与教学标注

> 本站首先教授“可迁移的判读框架”，不把任一国家/地区指南当作唯一答案。遇到治疗阈值、药物剂量、电击能量与时间窗，必须回到当地现行指南、设备和患者情况。

## 房颤：AHA/ACC 与 ESC 的差异（教学摘要）

| 主题 | 美国 ACC/AHA/ACCP/HRS（2023） | 欧洲 ESC（2024，AF-CARE） | 教学提示 |
|---|---|---|---|
| 卒中风险评分 | CHA₂DS₂-VASc（含性别类别） | CHA₂DS₂-VA（去掉性别类别） | 不能把两套评分直接互换；看原文阈值与推荐等级 |
| 抗凝决策 | 按评分与出血风险个体化 | 强调合并症管理、动态再评估与患者路径 | 评分只是起点，不是自动处方 |
| 节律控制 | 早期节律控制在合适患者中更重要 | AF-CARE 路径，节律控制/消融地位提升 | 心衰、症状负荷与病程会影响选择 |
| 合并 PCI 的抗栓 | 关注三联治疗时程与出血风险 | 更强调尽早停用阿司匹林、缩短三联 | 具体天数按指南与出血/缺血风险 |

## ACS / STEMI

- 再灌注时间窗、转运策略与溶栓后转诊路径在不同地区/中心能力下不同。
- 心电图教学重点：相邻导联、镜像改变、后壁/右室扩展、左束支阻滞与既往起搏时的判断边界。
- 不应把“某国指南的分钟数”当作全球统一质控指标；本站只讲概念与判读，不给个体化溶栓/抗凝方案。

## ACLS / 复苏

- AHA ACLS 与 ERC/ILCOR 在按压质量、除颤能量范围、肾上腺素时序、可逆病因与复苏后温度管理上的推荐细节存在差异。
- 本站急救模拟以“高质量 CPR、尽早除颤、减少中断、按可逆病因处理”为核心；具体能量与药物以场景提示和当地流程为准。
- 妊娠、低温、LAST、PEA 低血容量等特殊场景，不同指南的“何时停/何时做”阈值不同；模拟评分是教学规则，不是法律或伦理标准。

## 儿科

- PALS 与欧洲儿科生命支持在通气优先、能量计算、药物剂量与团队角色上存在差异。
- 儿科心电图判读需结合年龄、心率、右室优势与先天性心脏病史，不能直接套用成人标准。

## 本站如何标注

1. 章节中的诊断标准尽量使用“形态/间期/导联”描述，而不是绑定单一指南编号。
2. 处理原则写成“方向 + 边界”，不写成个体化处方；剂量/能量只在急救模拟的教学提示中出现。
3. 指南差异在 `docs/GUIDELINES.md` 与 `#/about` 说明；不把争议写成定论。
4. 发现表述错误请走 [`CORRECTIONS.md`](CORRECTIONS.md)。
