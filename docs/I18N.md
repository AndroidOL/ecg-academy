# 国际化与双语术语

## 当前范围（beta）

- 支持中文（默认）与英文**导航外壳**：侧栏、顶部/底部导航、页脚“关于/勘误”、品牌副标题。
- 语言选择保存在 `localStorage: ecg-locale`；切换后刷新页面。
- 课程正文、题库与急救文本仍以中文为主；英文用户可通过 `#/glossary` 的 62 个中英术语对照阅读。
- 明确标注 beta，不宣称全站英文完成。

## 设计

- `public/static/js/i18n.js`：字典、`getLocale()`、`setLocale()`、`t()`、`navKey()`。
- `data` 与页面正文不硬编码英文翻译；避免半翻译造成医学歧义。
- 语言切换设置 `document.documentElement.lang`，便于读屏与浏览器断词。
- 英文界面下 ACLS 徽标不重复显示（导航标签本身已是 ACLS）。

## 新增术语

在 `public/static/js/views/glossary.js` 的 `TERMS` 数组增加：

```js
['分类', 'English term', '中文术语', '一句中文定义'],
```

分类会由数组自动生成；搜索同时匹配中英文与定义。

## 全站翻译路线

1. 先建立“界面字符串 → 术语 → 课程标题”三层 key，避免逐页硬编码。
2. 课程正文由医学顾问与译者结对翻译；保留中文原文与版本号。
3. 术语表作为 canonical glossary；翻译中的术语必须引用同一词条。
4. 区域指南差异单独标注，不把某一地区指南当成全球唯一答案。
5. 翻译内容与中文内容分别做医学审阅；未审阅翻译标注 `translation_status: draft`。

## 已知风险

- 直译可能改变剂量、能量、适应证语义；医学句子必须人工审阅。
- 课程标题短、导航长；英文文本膨胀可能破坏移动端布局，需回归 320px。
- 英文字母缩写（如 AF、VT、PEA）在不同地区可能有不同习惯，保留中英对照。
