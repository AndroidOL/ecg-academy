# 医学顾问与审阅者

## 当前名单

**尚无已签约的临床医学顾问。** 当前版本为编辑整理版，全部章节标注“编辑核对 · 待临床同行审阅”；这不是临床指南，也不冒充已审阅教材。

## 我们需要谁

- 心内科（电生理、冠脉、心衰）
- 急诊科 / 重症医学（ACLS、复苏、中毒）
- 儿科 / 新生儿（PALS、先天性传导异常）
- 心电图室 / 心电生理技术人员（操作、伪差、设备）
- 医学教育/模拟教学（评分与复盘效度）

## 顾问职责

1. 按章节核对机制、诊断标准、鉴别、危险信号、处理与剂量/能量边界。
2. 指出需要删除或降级表述的内容，尤其是可能造成临床误用的句子。
3. 每年或指南更新时复审；对重大争议给出“存在分歧”的标注。
4. 申报利益冲突（厂商、课程、付费平台等）。

## 记录方式

在 `data/review.php` 的对应章节增加：

```php
'clinicalReviewers' => ['姓名（机构，YYYY-MM-DD）'],
'status' => 'clinical_reviewed',
'statusLabel' => '临床同行审阅 · 已记录顾问',
```

如顾问要求匿名，只记录“心内科顾问 A（YYYY-MM-DD）”。未经本人同意不得公开姓名。

## 参与方式

通过 GitHub Issue 标题 `[Medical Review] 意向领域` 联系维护者，或从 `README` 的仓库入口发起讨论。请勿在公开 Issue 中提交患者信息。
