# 无障碍审计（WCAG 2.2 AA 目标）

> 范围：前端 SPA（首页、课程、练习、每日挑战、急救、向量、实验室、复习、关于、术语表、我的、管理后台登录）。本审计是工程自检，不等同于第三方认证或真实辅助技术用户走查。

## 已落实

- `viewport` 允许缩放，未设置 `maximum-scale=1` / `user-scalable=no`。
- 全局 `:focus-visible` 2px 品牌色轮廓；弹窗实现焦点陷阱、Esc 关闭、关闭后返回触发元素。
- 跳过导航链接 `跳到主要内容`；`main#main` 地标；导航当前项 `aria-current="page"`。
- 主题切换、低带宽、语言切换有可读文本；图标按钮使用 `aria-label`。
- 练习反馈区域 `role="status" aria-live="polite"`；AI/复习提示避免只在视觉上变化。
- 波形 canvas 均有 `aria-label`；胸导联 SVG 电极和心脏解剖热点可键盘聚焦，Enter/Space 触发。
- 每日挑战日历每格带完整日期与成绩 `title`；激活顺序步骤按钮为 `role="tab"` + `aria-selected`，进度条与读数均有文本替代。
- 文章插图 SVG 均为 `role="img"` 且带 `aria-label`，图例以文本呈现，不单独依赖颜色。
- `prefers-reduced-motion: reduce` 与低带宽模式关闭非必要动画；ECG 播放仍由用户控制。
- 移动端单列、44px 触控目标、16px 输入字号、安全区适配；横向无滚动（回归视口 320/390/768/1280）。
- 表单字段有可见 label；错误信息与提交按钮状态可见。
- 深浅主题均使用语义 CSS 变量；正文对比度目标 ≥4.5:1，大字号 ≥3:1（工程核对，未逐色值认证）。

## 已知限制

- 230 章课程内容以中文为主；英文为导航外壳 + 62 词术语表 beta，尚非全站双语。
- Canvas 波形本身不是可读的表格数据；提供导联、速率、标注与文字解释作为等价信息，但复杂形态仍需视觉判读。
- SVG 解剖/胸导联图的精细区域在极窄屏上触控目标可能小于 44px；提供列表按钮作为替代。
- 管理后台的部分数据表格在手机上横向滚动，尚未改为卡片式。
- 尚未完成真实读屏（NVDA/JAWS/VoiceOver）用户测试；欢迎协助。
